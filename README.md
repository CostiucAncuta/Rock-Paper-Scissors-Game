# Rock-Paper-Scissors-Game

The Mission: 

You decide that kids these days only know about Fortnite and Tik Tok, but have no clue about great old games like a rock-paper-scissors game. Time to build the next viral (retro) game!

🌱 Must-have features:

1. Have three buttons that the player can press to pick their weapon of choice (feel free to use emoji's for this)

1. Have a play button to have the computer pick one randomly

1. Announce the winner

1. No alert box, add a message to your html

1. Possible outcomes: draw (when both chose the same thing) or player won/lost
   
1. Show a play again button after a game ended
   
1. Nice graphics
   
1. Different end message styling depending on the outcome (hint: you might need to add or remove classes via JavaScript for this)

🌼 Nice-to-have features
* Keep track of the score after multiple games
